## STEP 1 — MATCH THE ARKDATA DESIGN LANGUAGE (make it look native)
--------------------------------------------------------------------------------
The shipped ArkData app is React 18 + Vite + Tailwind + shadcn/ui (Radix) +
TanStack Query, charts via **recharts**. Match THIS, not the gold marketing
brand. Exact primitives to mirror:

DESIGN TOKENS (shadcn neutral base, HSL, ship BOTH themes; default = dark):
  Light:  --background 0 0% 100%;  --foreground 0 0% 3.9%;  --card 0 0% 100%;
          --muted 0 0% 96.1%;  --muted-foreground 0 0% 45.1%;
          --border 0 0% 89.8%;  --radius 0.5rem;
  Dark:   --background 0 0% 3.9%; --foreground 0 0% 98%;  --card 0 0% 3.9%;
          --muted 0 0% 14.9%;  --muted-foreground 0 0% 63.9%;
          --border 0 0% 14.9%;  --sidebar-background 240 5.9% 10% (slate).
  Chart palette (dark): --chart-1 220 70% 50%; -2 160 60% 45%; -3 30 80% 55%;
          -4 280 65% 60%; -5 340 75% 55%.  Always override recharts colors with
          these — never library defaults. Semantic: emerald=above goal, rose=below.

PER-TENANT ACCENT: a single accent color (default purple #7c3aed) applied as
  inline tint — active nav item = backgroundColor `${accent}15` + color `accent`;
  avatar chip = `${accent}20`. Make accent a prop/CSS var so a tenant can rebrand.

LAYOUT (this is the #1 gap — the current app uses a top toggle, not a sidebar):
  • Persistent LEFT SIDEBAR: 240px expanded / 68px collapsed (icon + tooltip).
    Section headers 12px uppercase muted; active item = tinted bg + accent text +
    accent icon. Tenant switcher at top, user chip at bottom. Collapse toggle.
  • TopBar: page title + persistent filter bar (see gaps) + dark/light toggle +
    notifications. MobileNav: sidebar collapses to a drawer; full mobile parity.
  • Card/elevated surfaces (shadcn Card: CardHeader/CardTitle/CardContent),
    rounded-lg, subtle border, generous padding. Progressive disclosure > density.

CHART KIT (mirror these component contracts so it ports cleanly):
  • FunnelChart({ title, stages })  — stages:[{label,value}]; per-stage bar width
    = value/max, plus stage-to-stage conversion %.
  • SankeyChart({ title, stages, flows }) — flows:[{from,to,value}]; multi-touch
    path view. (Current app has NO sankey — add it.)
  • HeatmapChart({ title, ... }) — channel × week, red↔green vs goal.
  • KPICard / MetricCard — one big number (28–32px) + ONE comparison (vs prior
    period) + ONE micro-viz (sparkline). "Never show a naked number."
  • TrendChart / AdvancedTrendChart — real recharts LINE time-series (current app
    only has sparklines — add real line charts).

## LOCKED SEMANTICS — preserve exactly (do NOT redesign the logic)
--------------------------------------------------------------------------------
• TWO funnels with a top-level toggle:
   – PEOPLE funnel = person-level deterministic, pixel-verified:
       uploaded → audience → landing-page → converted → booked → closed.
       Has a Who / Source drill toggle. NO attribution-model selector here.
   – MARKETING funnel = aggregate: impressions → clicks → visits → leads →
       conversions → closed. Attribution-model selector lives HERE only.
• RECONCILIATION = "how many REAL people?" Each platform reconciled on its OWN
  (e.g. Meta 96→61, Google 58→50), then composed into ONE pixel-verified truth
  (89 = Meta-only 33 · overlap 28 · Google-only 22 · pixel-only 6).
  NEVER show a summed/stacked combined number. One truth, shown as composition.
• ATTRIBUTION = "WHO gets credit?" Total conversions are FIXED; the model
  (first / last / linear / time-decay / data-driven) only RE-SPLITS credit across
  channels. Show credit-by-channel bars + a channel×model comparison matrix.
  Reconciliation and attribution are DIFFERENT surfaces — don't merge them.
• PERSONA / PORTFOLIO views: role hierarchy admin > meta_partner > partner >
  tenant. A persona switcher; higher roles see a portfolio roll-up (aggregate
  KPIs + sparklines + notices) with breadcrumb drill-down into a tenant's funnel.
